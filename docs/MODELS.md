# 운영 중인 예측 모델

서비스에서 지금 돌고 있는 예측 모델 9개(도매 3 · 소매 6)를 한곳에 모은 문서다.
코드가 1차 출처다. 숫자를 바꾸면 이 문서와 파이프라인 파일 맨 위 설명을 같이 고친다.

- 실험·선택 과정은 KCSP-konkuk/model-research 레포(2026-10-02 redpepper 에서 이름 변경)에 있다: 홍고추 도매 `METHOD.md`, 소매 `docs/RETAIL.md`
- 배치 실행·타이머·로그는 [`KCSPmodel/batch/README.md`](../KCSPmodel/batch/README.md), 배포는 [CONTRIBUTING.md](../CONTRIBUTING.md)

마지막 갱신: 2026-10-02 (오이 소매 예측 추가)

---

## 1. 한눈에

모두 **순(1\~10일 상순 / 11\~20일 중순 / 21일\~ 하순) 단위로 진행 중인 순 1개를 예측**한다(1순 뒤). 모델은 전부 XGBoost 다.

| 구분 | 품목 | 맞히는 가격 | 파이프라인 | 결과 테이블 | 실행 (KST) |
|---|---|---|---|---|---|
| 도매 | 배추 | 가락시장 경매가 (농넷) | `pipeline.py` | `cabbage_predictions` | 05:30 |
| 도매 | 양파 | 가락시장 경매가 (농넷) | `pipeline_onion.py` | `onion_predictions` | 05:50 |
| 도매 | 홍고추 | 가락시장 경매가 상, 10kg (농넷) | `pipeline_redpepper.py` | `redpepper_predictions` | 06:10 |
| 소매 | 붉은고추 · 양배추 · 양파 · 애호박 · 시금치 · 오이 | 서울 경동·복조리 전통시장 평균 소매가 (KAMIS) | `pipeline_retail.py` | `retail_predictions` | 12:10 |

화면: 도매는 상세 화면(가격 추이 · 예측 적중 이력), 소매는 홈 '서울 전통시장 소매가' 카드.

### 성능 보는 법

- **MASE** = 모델 오차 ÷ 나이브(직전 순 가격 유지) 오차. 1 보다 작으면 나이브보다 낫다. 품목마다 원래 출렁이는 정도가 달라서 MAPE 로 품목끼리 견주면 안 된다
- 소매 6품목과 홍고추는 **검증 구간에서 고르고 시험 구간에서 한 번 쟀다**(3분할). 배추·양파 도매는 그렇게 나눠 고른 모델이 아니다 — 원래 팀 모델을 옮겨 왔고 2025 홀드아웃만 있다

## 2. 도매

### 2.1 배추 — `pipeline.py`

| 항목 | 내용 |
|---|---|
| 타깃 | 순 평균 가격 (직접 맞힘) |
| 입력 | 가격 자기이력(lag·이동평균·전년), 반입량, 네이버 검색량(배추), 기상 — ASOS 해남(261)·태백(216, 7\~9월), 일사는 목포(165)·대관령(100) |
| 피쳐 | 후보 77개 중 고정 32개 (`SELECTED`) |
| 모델 | XGBoost `n_estimators=500, max_depth=3, learning_rate=0.05, subsample=0.8, colsample_bytree=0.8`, 단일 모델 |
| 학습 데이터 | 레포 `data/hist_*.csv`(2018\~2025) + DB 2026\~ |
| 성능 | 2025 홀드아웃 R² 0.804 / MAPE 11.6%. 2026 백테스트(1월 상순\~9월 중순 26순) 평균 오차율 11.41% |
| 약한 곳 | 6월 중순\~7월 하순 (봄배추 → 고랭지 전환기, 오차 21\~31%) |

### 2.2 양파 — `pipeline_onion.py`

| 항목 | 내용 |
|---|---|
| 타깃 | 순 평균 가격 (직접 맞힘) |
| 입력 | 가격 자기이력·평년, 반입량, 환율(원/달러·원/위안), CPI·PPI, 기상 — ASOS 밀양(288), 일사는 거창(264) |
| 피쳐 | 고정 40개 (`SELECTED`). 유가는 뺐다(빼는 쪽이 2025 홀드아웃에서 나았다) |
| 모델 | XGBoost `n_estimators=300, max_depth=2, learning_rate=0.03, subsample=0.9, colsample_bytree=0.8`, 1\~4월 표본 가중 1.5 |
| 학습 데이터 | 레포 CSV(2018\~) + DB 2026\~ |
| 성능 | 2025 홀드아웃 R² 0.830 / MAPE 7.8%. 2026 백테스트 평균 오차율 10.89% |
| 약한 곳 | 3월 상순\~4월 중순 (저장 → 햇양파 전환기, 21\~29%) |
| 주의 | 양파는 원래 가격이 완만해 **나이브가 매우 강하다.** 1순 뒤 MASE 로 재면 나이브를 넘지 못한다 |

### 2.3 홍고추 — `pipeline_redpepper.py`

| 항목 | 내용 |
|---|---|
| 타깃 | `대상 순 가격 ÷ 직전 순 가격` (비율). 예측가 = 비율 × 직전 순. 해마다 가격대가 크게 달라 직접 맞히면 트리가 새 가격대를 못 따라간다 |
| 입력 | 농넷 순별 홍고추·풋고추·청피망 가격·평년·전년, 농넷 일별 직전 8거래일 막판 가격, 네이버 검색량(홍고추·고추·고춧가루·김장, 2016\~ 한 번에) |
| 피쳐 | 학습 때마다 중요도 상위 60개(`K_TOP`) |
| 모델 | XGBoost 절대오차(`reg:absoluteerror`) `max_depth=5, n_estimators=1200, learning_rate=0.08, subsample=0.8, colsample_bytree=0.9, min_child_weight=12, reg_lambda=1.0`, 시드 12개 평균 |
| 학습 데이터 | 레포 CSV(2001\~) + 서버 캐시. DB 는 읽지 않는다 |
| 선택 · 평가 | 검증 2016\~2020 에서 선택, **시험 2021\~2025 MASE 0.659 / MAPE 16.1%** (model-research `METHOD.md` 11절). 2026 백테스트 평균 오차율 16.61% |

## 3. 소매 — `pipeline_retail.py`

### 3.1 여섯 품목 공통

| 항목 | 내용 |
|---|---|
| 맞히는 값 | KAMIS 서울(1101) 상품(04) 등급 소매가 중 **경동 · 복조리 두 전통시장의 그날 값 평균**(있는 곳만) → 순 평균 |
| 왜 서울 평균이 아닌가 | KAMIS 서울 평균에는 대형유통(익명 A\~L-유통)이 섞여 있고, 판매처 구성이 바뀌면 가격 변화 없이 평균이 출렁인다. 경동(2014-01\~)·복조리(2014-07\~)는 그동안 계속 조사됐다 |
| 타깃 | `y[t] / y[t-1]` (비율), 예측가 = 비율 × 직전 순 |
| 쓰는 정보 | 소매·가락 모두 **대상 순 시작일 전날까지만** |
| 피쳐 | 소매 자기이력(변화율·전년·평년·경동/복조리 비·경직성) + 가락 일별(순 평균 변화·막판·마진) + 소매 막판(직전 순 마지막 조사일 ÷ 순 평균). 24개 (오이는 소매 막판 없이 22개) |
| 모델 | XGBoost 절대오차, **검증 상위 5개 설정 × 시드 12 평균**(60개). 설정마다 피쳐 전부 또는 중요도 상위 15개 |
| 학습 | 2014-07 상순 \~ 직전 순 (매일 새로 학습) |
| 선택 · 평가 | 검증 2017\~2021 에서 피쳐 그룹·파라미터 선택 → **시험 2022\~2025 (144순)** 1회. 2026 은 어떤 결정에도 쓰지 않았다 |

피쳐 그룹을 품목마다 따로 골랐는데, 다섯 품목은 같은 뼈대(소매 + 가락 + 소매 막판)가 뽑혔다. 시금치만 달력(월 · 순 · 연중 순 번호) 3개가 더 붙었고, 오이는 소매 막판도 기준을 못 넘어 소매 + 가락만 남았다(파이프라인 `GROUPS`).
기상·반입량·검색량·교차 가격·대형유통 가격은 1순 뒤에서 효과가 없었다.

### 3.3 가락 자리에 무엇을 넣나

소매 모델의 힘은 대부분 가락 가격에서 나온다(빼면 MASE 0.93\~0.97).

- **붉은고추 · 양배추 · 양파** — 농넷 가락 경매가(상) 일별. 레포 `data/hist_daily_*.csv`(2018 이전은 농넷 백필) + DB `agri_price`
- **애호박 · 시금치 · 오이** — KAMIS 16번 도매(`periodWholesaleProductList`) 서울 '가락도매'(중도매인 판매가). DB `wholesale_market_price` 만 읽는다
  - 새 품목마다 농넷 일별 백필이 약 630회 요청이라 KAMIS 로 대신했다. 기존 3품목에서 경매가 자리에 KAMIS 도매를 넣어도 검증 MASE 차이가 ±0.03 안이고 순서도 같았다(`RETAIL.md` 12.1)
  - 백엔드 `KamisWholesaleService` 가 2014\~ 를 연 단위로 적재하고, 09:30·17:30 에 최근 14일을 다시 받는다. 당일 값은 15:30 무렵 게시(1회 관측)라 17:30 에 들어오고, 다음 날 12:10 예측에 쓰인다

### 3.4 배치가 예측을 건너뛰는 경우

틀린 예측을 쓰느니 그 순은 비워 둔다(오류로 끝나지 않는다).

- 학습 가능한 순이 300개 미만 — 소매 첫 적재 전
- 직전 순 소매가가 없음 — 첫 적재 도중이거나 직전 순 조사가 아직 없음
- (애호박·시금치·오이) 직전 순 KAMIS 도매가가 없음 — 백엔드 첫 적재는 소매 다음에 도매를 받는다

예측 대상 행에 필수 피쳐(`r_chg1`·`g_chg1`·`r_last_vs_mean`·`margin` 중 그 품목에 있는 것)가 비면 오류로 끝난다.

### 3.5 알고 쓸 것

- 순이 바뀌는 날(1·11·21일)엔 12:10 배치 전까지 이번 순 예측이 없다. 그동안 홈 카드는 '다음 순 예측 · 오늘 12시 공개'를 보여준다(KST 13시 전). 배치를 당길 수 없는 건 직전 순 마지막 날 가락 경매가가 11:00 에 들어오기 때문
- 학습에 쓴 KAMIS·농넷 과거값은 2026-09 에 받은 최종값이다. 게시 후 고쳐진 값이 있었다면 그때 알 수 있던 값과 다를 수 있다
- 피쳐 이름·계산을 바꾸면 `tests/test_pipeline_retail.py` 의 기준 목록부터 맞춘다. 실험과 같은지 확인하는 방법: model-research 의 `data/retail/*.csv` 로 표를 만들어 `pred_{품목}5_h1_2026.csv` 의 202601상순 예측과 비교한다(2026-10-01 애호박·시금치, 10-02 오이 일치 확인). 202601상순만 견준다 — 실험은 2026 행을 학습에 안 넣어서 그 뒤 순은 다르다
- 보류 후보: 배추 소매(시험 0.628 이지만 2025\~2026 0.80), 상추(정식 절차 전)
