## 1. 다시 본 서비스

| 화면 | 잘 되는 것 | 아쉬운 것 |
|---|---|---|
| 홈 | 첫 문장으로 정체성이 보인다. 작업대 미리보기 · 템플릿 · 오늘의 요약으로 바로 들어간다 | 첫 로드가 무겁다(한 번에 752KB, gzip 227KB — 작업대 · 요약 · 상세 코드를 홈에서 같이 받는다). 링크를 메신저에 보내면 미리보기 문구가 없다 |
| 분석 › 작업대 | 지표 61개를 주기 · 변환 · 시차로 맞춰 6가지 차트로 본다. 조건 · CSV · 이미지 · 링크 | **무엇을 볼지 · 결과를 어떻게 읽을지를 사용자가 다 해야 한다.** 고른 조합에서 의미 있는 관계를 대신 찾아 주지 않는다(시차 상관 표를 직접 열어 읽어야 한다). 지표마다 마지막 날이 달라도 고를 때 알기 어렵다 |
| 분석 › 오늘의 요약 | 품목마다 한 줄 결론 · 요인 · 상황판 · 사건 · 비슷한 과거 · 흐름, 카드마다 작업대로 | **예측이 맞았는지가 화면 어디에도 없다** — `retail_predictions` 에 순마다 예측 · 실제 · 오차가 쌓이는데 쓰지 않는다 |
| 상세검색 | 가락 도매가 추이, 도매 AI 예측(배추 · 양파 · 홍고추), 예측 적중 이력 | 메뉴 이름이 하는 일(도매 예측)과 맞지 않는다. 소매 예측 6품목과 따로 논다 |
| 커뮤니티 | 품목 방 · 순별 투표 · 시세 브리핑 자동 글 | 작업대에서 찾은 것을 글로 남길 길이 없다(링크를 붙여도 미리보기 없음) |

데이터 쪽에서 본 것
- 산지 기상은 3곳(해남 · 태백 · 밀양)을 **모든 품목에 같이** 쓴다(인사이트 · 날씨 템플릿). 관측소 11곳은 품목과 이어지지 않는다
- 반입량 CSV 에 순마다 1 · 2위 산지가 있고, 관측소 11곳이 바로 그 주산지들이다 → 품목별 "그 순의 주산지 날씨"를 만들 수 있다. 다만 산지 칸은 레포 CSV(당근 · 양배추 · 홍고추, 손으로 갱신, 2026-09 까지)에만 있어 **자동으로 이어 받을 출처가 먼저** 필요하다

## 2. 방향

> "고르면 보여 주는 도구" → **"찾아 주고, 이어 주고, 남기는 도구"**

- **찾아 주기** — 고른 지표에서 함께 움직인 관계 · 앞서 움직인 지표를 자동으로 찾아 쉬운 문장으로, 사례 수와 함께
- **이어 주기** — 예측 ↔ 실제(적중 기록), 산지 ↔ 날씨 ↔ 가격
- **남기기** — 내 분석 저장, 커뮤니티 글에 작업대 붙이기

## 3. 작업 순서 (PR 단위)

| # | PR | 내용 | 확인 |
|---|---|---|---|
| U1 | **자동 발견 · 신선도 · 가벼운 첫 화면** | ① 작업대 '찾아낸 것': 고른 지표 쌍마다 시차 상관(0~12순)을 계산해 가장 강한 관계 3개를 문장으로("경매가가 2순 앞서 소매가와 함께 움직였어요 · r 0.78 · 349순"). 계절 · 추세로 부풀지 않게 원값 · 지수 지표는 전년 대비로 맞춰 계산. 누르면 그 시차를 건 겹쳐 보기 · 산점도로 ② 지표 목록 · 고른 지표에 마지막 날, 멈춘 지표 표시 ③ 페이지별로 나눠 받기(작업대 · 요약 · 상세 · 커뮤니티는 들어갈 때) ④ 메신저 미리보기 문구(og 태그) | vitest(발견 순위 · 멈춤 판정), 빌드 크기, 화면 |
| U2 | **예측 적중 기록** | ① 통합 시계열에 `forecast:{품목}`(다음 순 예측가) · `forecast_error:{품목}`(오차 %) 추가(`retail_predictions`) → 작업대에서 예측 ↔ 실제를 겹쳐 본다 ② 오늘의 요약 한 줄 결론에 "최근 12순 평균 오차 n%" · 맞힌 방향 비율 ③ '상세검색' 메뉴 이름을 하는 일에 맞게('도매 예측') | 배치 테스트, 화면 |
| U3 | **남기기** | ① 로그인 사용자 '내 분석'(작업대 상태 저장 · 이름 · 메모, 마이페이지 목록) ② 커뮤니티 글쓰기에 작업대 붙이기 → 글에 미니 차트 미리보기 | 백엔드 테스트, 화면 |
| U4 | **산지와 주산지 날씨** | 산지 칸을 자동으로 받을 출처 확인(서울시농수산식품공사 반입량 API 의 산지별 항목 등) → 품목 · 순별 1 · 2위 산지 지표, 산지 달력(한 해 중 어디서 오나), "그 순 주산지 관측소" 기상 지표 → 날씨 템플릿 · 인사이트가 품목에 맞는 산지를 쓴다 | 출처 조사 결과에 따라 범위 확정 |

순서 이유: U1 은 지금 데이터로 바로 체감이 크고(화면만), U2 는 이미 쌓인 데이터를 쓰는 신뢰도 보강, U3 은 백엔드가 필요한 재방문 기능, U4 는 출처 확인이 먼저다.
